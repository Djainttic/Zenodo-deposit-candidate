# Data dictionary

## `MIMO_orthogonal90.s2p`

- Format: Touchstone 2-port export from CST Microwave Studio.
- Export unit: GHz.
- Value format: magnitude/angle (`MA`).
- Reference impedance recorded in the file header: 50 ohm.
- Columns: frequency, S11 magnitude, S11 angle, S12 magnitude, S12 angle, S21 magnitude, S21 angle, S22 magnitude, S22 angle.
- The header also records the CST project context and selected geometric/material parameters.

## `hfss cst s11.xlsx`

The workbook contains the following sheets in the supplied archive:

- `maxG_eff_initial`
- `BGP_s11_single Element`
- `MIMO_orthogonal`
- `MIMO_Parallel 1ON`
- `MIMO_F2F_ON1`
- `Sheet1`

The workbook is preserved without alteration. The authors should confirm the meaning and units of every column before publication of the Zenodo record.
